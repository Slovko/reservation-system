# Домашня робота з JavaScript: три практичні завдання

## Завдання

1. **Калькулятор зарплати** обчислює виплати, додає бонус 10% за понад 160 годин і підсумовує витрати.
2. **Каталог онлайн-курсів** фільтрує, відображає, шукає та сортує курси, обчислює середню ціну.
3. **Бронювання готелю** бронює доступні номери, застосовує знижку 15% від п'яти ночей та повідомляє про помилки.

## Структура

- task-1-payroll/main.js
- task-2-courses/main.js
- task-3-hotel/rooms.js
- task-3-hotel/booking.js
- task-3-hotel/main.js
- task-3-hotel/index.html
- README.md

## Запуск

З каталогу javascript-homework виконайте команди node для перших двох завдань:

    node task-1-payroll/main.js
    node task-2-courses/main.js

Для третього завдання запустіть локальний сервер:

    python -m http.server 8000

Відкрийте http://localhost:8000/task-3-hotel/ і перегляньте консоль браузера.

## Використані можливості JavaScript

for...of, filter(), map(), find(), sort() на копії масиву, import, export, console.log(), console.table(), console.group().
